# Espanhol Cantando

Site estático da oferta Espanhol Cantando, preparado para GitHub e Vercel.

## Publicar na Vercel

1. Crie um repositório vazio no GitHub.
2. Envie **todo o conteúdo desta pasta para a raiz do repositório**.
3. Na Vercel, escolha **Add New → Project** e importe o repositório.
4. Em **Framework Preset**, selecione **Other**.
5. Deixe **Root Directory** como `./`.
6. Não informe comando de build nem pasta de saída.
7. Clique em **Deploy**.

O arquivo `index.html` está na raiz. Imagens, áudios e prévias ficam em `assets/` e serão hospedados pela própria Vercel junto com o site.
